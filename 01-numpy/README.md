# NumPy

## 1. Introduction
NumPy là thư viện Python dùng để tính toán số học
và xử lý dữ liệu dạng mảng nhiều chiều.

## 2. Learning Objectives
Sau khi hoàn thành course, có thể:

- Hiểu ndarray.
- Tạo và thao tác với arrays.
- Indexing và slicing.
- Thực hiện các phép toán trên arrays.
- Hiểu broadcasting.
- Thực hiện các phép tính thống kê cơ bản.
